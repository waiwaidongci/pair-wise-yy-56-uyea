# 钢结构焊缝台账、无损检测和返修闭环平台

源提示词编号：13。覆盖构件与图纸焊缝台账、二维定位、焊工资质和检测比例预警、批量检测计划、缺陷记录、返修/复检状态、Apollo GraphQL 数据层、版本快照、签字锁定和完整追溯。

## 分级抽检（焊缝 + 缺陷 + 计划 + 审核快照）

- **组内层级**：按「图纸 + 接头类型」分组，层级随组内最差缺陷等级（Ⅰ–Ⅳ）与最大返修次数在 放宽(10%) / 正常(20%) / 加严(100%) 之间自动重算；缺陷等级或返修次数每变化一次修订号 +1，结果先挂「待确认」。
- **计划联动**：层级变更后，未开始（待执行）计划整单失效、样本回池，按新层级比例补入新样本并自动生成补样计划（失效计划记录 `replacedBy` 溯源）；执行中与已出报告的样本留在原批次不追溯。
- **不重复抽取**：样本一旦采用即标记，补样只从组内未采用焊缝中选；失效样本回池，保留失效痕迹不覆盖。
- **容量排队**：检验员与超声仪按每日容量排程，排不进去的样本写明缺口（缺哪种资源、顺延到哪一天），追加容量后顺延样本自动重新排队。
- **并发修改**：两人在同一组、同一修订上提交层级修改时，先到结果保留，后到内容登记为差异待处理，可「合并后到内容」（挂为待确认修订）或「保留先到结果」。
- **快照与回滚**：每次确认生成只读审核快照；调整失败可一键恢复上次确认的层级并继续，恢复时已采用样本不重复抽取。

核心逻辑在 `src/app/domain/sampling.ts`（重算引擎）与 `src/app/domain/tier-sync.ts`（并发协调），均为框架无关的纯函数/类，可脱离 UI 验证：

```bash
./node_modules/.bin/esbuild scripts/test-sampling.mts --bundle --platform=node --format=esm --outfile=/tmp/t.mjs && node /tmp/t.mjs
```
